## 五、提效规则（照做，别自由发挥）

1. 视频 **1.25–1.5 倍速**，每段只看 1 遍；不懂就回看那一个知识点，不整章重看。
2. **15 分钟规则**：卡住超过 15 分钟 → 记进当天"问题清单" → 问 AI / 查文档 → 继续；每周六统一清。
3. **24 小时规则**：任何模块 24 小时内必须有能跑的代码，否则停下看课去写码。
4. **不抄代码**：看完关掉视频自己写；报错先自己查 10 分钟。
5. **每天收尾 5 分钟**：`git commit` + 3 行日志（今天学了什么 / 卡在哪 / 明天第一件事）。
6. **周验收不过不欠账**：用周日机动时间补，连续两周不过就检查是不是"只看不写"。

## 十一、怎么用（每周固定动作）

1. 周日晚上打开 `study/plans/PROGRESS.md`，勾掉本周完成项，写下周"第一件事"。
2. 每天开始前打开对应 `weekNN-*.md`，只看当天那一行，别一次读完。
3. 每天结束做一次 `git commit`（提交信息：`week01-d3: 索引失效实验`）。
4. 落后 ≤2 天：周日补；落后 >3 天：按各周文件末尾的"减法清单"砍内容，**不整体延期**。
