# study 目录约定

## 一、当前有效的计划

- [`plans/README.md`](plans/README.md)：19 周计划索引 + 使用方法
- [`plans/PROGRESS.md`](plans/PROGRESS.md)：打卡表 / 里程碑 / 3 行日志 / 投递记录
- `plans/week00-*.md` ~ `plans/week19-*.md`：每周计划（v2）

## 二、产出放哪

| 类型 | 目录 | 示例 |
| --- | --- | --- |
| 学习笔记 | `notes/` | `notes/mysql-索引.md`、`notes/java-薄弱点清单.md` |
| SQL 脚本 | `sql/` | `sql/basics-review/`、`sql/sky-tables-v0.sql` |
| 项目代码 | `projects/` | `projects/web-crud/`、`projects/sky-take-out/`、`projects/heima-dianping/` |
| 算法代码 | `algorithm/` | 按周分目录，如 `algorithm/week01/` |
| 简历 | `resume/` | `简历-v1.md`、`简历-终版.md`、`岗位匹配表.md` |
| 面试资料 | `notes/面试/` | 模拟面复盘、错题本、项目 20 问 |

## 三、历史内容（保留，不再维护）

| 路径 | 说明 |
| --- | --- |
| `plans/archive/2026-09-v1/` | 旧版 17 周计划（4h/天），只读 |
| `plans/java/` | 早期 Java 笔记（HashMap 等） |
| `plans/JAVA coding/` | 早期刷题与练习笔记 |
| `plans/ds-practice/` | 早期 C 语言数据结构练习 |

> 历史笔记不删、不改，新内容一律进上表目录；需要引用旧笔记时在周文件里写路径。

## 四、每日提交规范

```
week01-d3: 索引失效8场景实验
week08-d4: JWT登录闭环
week13-d3: 简历v1
```

格式：`周次-天: 一句话做了什么`。当天没产出就不提交，不要攒到周末一次提交。
