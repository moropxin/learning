## 题目：两数之和

- 题号：1
- 难度：简单
- 使用方法：哈希表
- 核心思路：
  - 遍历数组
  - 计算当前数字还需要的数字
  - 在哈希表中查找
  - 没找到就保存当前数字和下标
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- 易错点：
  - 先查找，再保存当前元素
  - 返回的是下标，不是数字

## 题目：删除有序数组中的重复项

- 题号：26
- 使用方法：双指针
- 核心思路：
  - fast 负责遍历
  - slow 负责保存不重复元素

- 空间复杂度：O(1)
- 易错点：
  - 返回 `slow + 1`

## 题目：反转字符串

- 题号：344
- 使用方法：左右双指针
- 核心思路：
  - left 从左边开始
  - right 从右边开始
  - 交换两个位置的字符
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 易错点：
  - 循环条件使用 `left < right`
  - 不需要额外创建新数组
