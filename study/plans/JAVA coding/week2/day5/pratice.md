## 题目描述

-题目：和为 S 的最长连续子数组（正整数版）

-描述：给定一个只包含正整数的数组和一个正整数 S，求和恰好等于 S 的最长连续子数组的长度。如果不存在，输出 0。
-输入格式（示例风格）：
-第一行：两个正整数 n S（1 ≤ n ≤ 100000，S ≤ 10^18）
-第二行：n 个正整数，数组元素 ≤ 10^9

-输出：一个整数，表示满足和为 S 的最长连续子数组长度（不存在则输出 0）。
-样例 输入: 5 9 1 2 3 4 5 输出: 3 （解释：子数组 [2,3,4] 的和为 9，长度 3，是最长的）

#
## 样例
输入:
```
5 9
1 2 3 4 5
```
输出:
```
3
```

## 解题思路（简明）
- 方法概述：例如“由于数组元素均为正，使用双指针（滑动窗口）维护区间和；右指针扩张，当前和超过 S 时左指针收缩；每次等于 S 时尝试更新答案。”
- 关键步骤：
  1. 初始化左右指针 left=0，sum=0，maxLen=0。
  2. 右指针从 0 到 n-1：sum += a[right]；当 sum > S 时移动 left 并减去 a[left]。
  3. 若 sum == S，则更新 maxLen = max(maxLen, right-left+1)。
- 适用条件：数组元素均为正。若允许负数，需用前缀和 + HashMap。


## 复杂度分析
- 时间复杂度：O(n)（每个元素最多入/出窗口一次）  
- 空间复杂度：O(1)（除输入外）


## 常见错误 / 易错点
- 用 int 存储累加和导致溢出（应使用 long sum）
- 读入 S 时使用 int
- 左指针移动条件或循环边界写错（导致死循环或越界）
- 没考虑 n=0（若允许）或输入格式差异（换行/空格：使用s.nextLine()吸收）

## 变体 & 延伸
- 若元素可为负数：使用前缀和 + HashMap（记录 prefixSum -> 最早下标），求最长子数组长度。
- 求满足 sum ≤ S 的最长子数组：滑动窗口适用，但更新条件变化。
- 统计子数组个数：前缀和 + HashMap（计数）。
