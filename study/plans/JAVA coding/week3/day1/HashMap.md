## 一、HashMap 概念快速入门

### 1. HashMap 是什么
HashMap 是 Java 集合框架中的一种常用映射（Map）实现，用来存储 key-value 对。

它的核心作用是：
- 把一个 key 映射到一个 value
- 之后可以通过 key 直接查到对应 value

例如：
- 学生姓名 -> 年龄
- 课程名 -> 分数
- 字符串 -> 出现次数

常见写法：
```java
Map<String, Integer> map = new HashMap<>();
map.put("Tom", 90);
map.put("Jerry", 85);
System.out.println(map.get("Tom")); // 90
```

### 2. HashMap 底层结构
HashMap 的底层本质可以理解为：
- 一个数组
- 每个数组位置叫作“桶”
- 桶里可以存放链表或红黑树（JDK 8 及之后）

因此，HashMap 的结构可以概括为：
- 数组 + 链表/红黑树

### 3. 为什么叫 HashMap
因为它使用哈希（Hash）算法来决定元素放到数组的哪个位置。

简单理解：
- key 会先计算 hash 值
- hash 值再决定它落在数组的哪个桶中
- 这样在查找时也能快速定位到位置

### 4. put() 的过程
当执行 `map.put(key, value)` 时，HashMap 大致会做这几步：
1. 计算 key 的 hash 值
2. 根据 hash 值确定数组位置（桶下标）
3. 如果该位置为空，直接放入
4. 如果该位置已经有元素：
   - 检查 key 是否相同
   - 相同则覆盖 value
   - 不同则发生哈希冲突
5. 冲突时，采用链表/红黑树继续存放

### 5. get() 的过程
当执行 `map.get(key)` 时：
1. 计算 key 的 hash 值
2. 根据 hash 值找到桶的位置
3. 在桶中比较 key 是否相同
4. 如果相同，则返回 value
5. 如果不同，则继续沿链表或树往后查找

### 6. 哈希冲突是什么
如果两个 key 的 hash 值不同，但计算后映射到同一个数组位置，就称为哈希冲突。

例如：
- key1 和 key2 在逻辑上不同
- 但经过 hash 运算后，落在同一个桶中
- 这时需要用链表或红黑树来解决

### 7. 扩容机制
HashMap 在元素越来越多时，会扩容。

默认：
- 初始容量：16
- 负载因子：0.75
- 当元素数量达到 16 × 0.75 = 12 时，开始扩容

扩容的意义：
- 减少哈希冲突
- 提高查找效率
- 保持整体性能更稳定

### 8. HashMap 的主要特点
- key 唯一：重复 key 会覆盖旧 value
- key 可以为 null（仅允许一个 null key）
- value 可以重复
- 不保证顺序
- 线程不安全

### 9. HashMap 与 Hashtable / TreeMap 的区别
- HashMap：高效、线程不安全、允许 null
- Hashtable：线程安全、效率较低、不能存 null
- TreeMap：按 key 排序，适合有序场景

### 10. HashMap 的学习重点
今天必须理解的关键点：
- HashMap 用来存 key-value
- 底层是数组 + 链表/红黑树
- 通过 hash 定位桶
- 冲突时使用链表或树处理
- put/get 都依赖 key 的 hash 和 equals
- 扩容是为了降低冲突，提高效率
