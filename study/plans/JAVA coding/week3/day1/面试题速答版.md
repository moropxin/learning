#HashMap 面试题速答版

## 1. HashMap 是什么？
- HashMap 是 Java 中常用的 Map 实现
- 它能把 key 映射到 value
- 适合做计数、去重、查找表等场景

速答：
- HashMap 是一种 key-value 集合，底层通过哈希实现快速查找。

## 2. HashMap 的底层结构是什么？
- 底层是数组
- 数组中的每个位置叫桶
- 后续在桶中存链表或红黑树
- 所以可以简单记为：数组 + 链表/红黑树

速答：
- HashMap 底层是数组加链表/红黑树，通过 hash 定位桶位置。

## 3. put() 的过程是什么？
- 先计算 key 的 hash 值
- 再根据 hash 定位桶
- 桶为空，直接放入
- 桶不为空，比较 key 是否相同
- 相同则覆盖旧 value
- 不同则发生冲突并继续挂链表/树

速答：
- put() 先 hash 定位桶，再比较 key；相同覆盖，不同冲突处理。

## 4. get() 的过程是什么？
- 先计算 hash
- 根据 hash 定位桶
- 在桶中比较 key
- 如果 key 相同，返回 value
- 如果不同，继续沿链表/树查找

速答：
- get() 通过 hash 找到桶，再在桶中比 key，最终返回对应 value。

## 5. 什么是哈希冲突？
- 不同 key 计算后可能落到同一个桶
- 这叫哈希冲突
- HashMap 通过链表或红黑树解决冲突

速答：
- 哈希冲突是不同 key 经过 hash 计算后落到同一位置，HashMap 用链表或红黑树解决。

## 6. 为什么 HashMap 访问速度快？
- 因为它不是从头到尾遍历
- 而是根据 hash 直接定位桶
- 常见情况下查找效率接近 O(1)

速答：
- 因为 HashMap 通过 hash 值直接定定位置信息，避免了全量遍历。

## 7. 为什么要扩容？
- 让数组不至于太满
- 减少冲突
- 提高效率和稳定性
- 默认容量是 16，负载因子 0.75

速答：
- 扩容是为了降低冲突，提高查询效率，避免桶过满导致性能下降。

## 8. HashMap 默认容量和阈值是多少？
- 默认容量：16
- 默认负载因子：0.75
- 阈值：16 × 0.75 = 12
- 当元素超过 12 时，触发扩容

速答：
- 默认容量是 16，负载因子是 0.75，达到 12 时扩容。

## 9. HashMap 能存 null 吗？
- 可以存 null key
- 也可以存 null value
- 但一般一个 null key 即可

速答：
- HashMap 允许 null key 和 null value，但不建议随意使用。

## 10. HashMap 和 Hashtable 的区别？
- HashMap：效率高，线程不安全，允许 null
- Hashtable：线程安全，效率相对低，不允许 null

速答：
- HashMap 更常用，速度更快；Hashtable 更安全但性能更差。

## 11. HashMap 和 TreeMap 的区别？
- HashMap：无序，查找快
- TreeMap：按 key 排序，适合有序场景

速答：
- HashMap 侧重效率，TreeMap 侧重有序性。

## 12. HashMap 和 HashSet 的区别？
- HashMap：存 key-value 对
- HashSet：存单个元素，底层本质也是通过 HashMap 实现

速答：
- HashMap 是映射结构，HashSet 是集合结构，前者存键值，后者存单一对象。

## 13. 为什么 HashMap 适合做计数题？
- 统计次数本质上就是 key -> count
- 每个字符/数字/单词都可以作为 key
- 计数很自然地用 Map 表示

速答：
- 因为计数问题本质上是“元素 -> 出现次数”的映射，HashMap 很适合。

## 14. HashMap 可能会出现什么问题？
- 哈希冲突导致链表变长
- 极端情况下性能下降
- 线程不安全，多线程下容易出现并发问题

速答：
- HashMap 的主要问题是哈希冲突和线程不安全，极端情况下性能会下降。

## 15. 最简答版总结
- HashMap 是 key-value 集合
- 底层是数组 + 链表/红黑树
- 通过 hash 定位桶
- 冲突时挂链表/树
- 扩容是为了减少冲突，提高效率

## 16. 面试口播模板
可以直接照着说：

“HashMap 是 Java 中常用的 Map 实现，用来存放 key-value 键值对。它的底层是数组，每个位置叫桶，桶中可以存链表或红黑树。存取时，先对 key 计算 hash 值，再根据 hash 定位桶位置。如果桶为空就直接放入；如果不为空则比较 key 是否相同，相同覆盖，不同发生哈希冲突。哈希冲突会通过链表或者红黑树来解决。它默认容量是 16，负载因子 0.75，达到阈值后扩容。HashMap 的优点是查找效率高，适合做计数、去重和映射表等场景。它不保证顺序，也不是线程安全的。和 Hashtable 相比，HashMap 更快但线程不安全；和 TreeMap 相比，HashMap 更关注查找效率，而 TreeMap 更关注顺序。”

## 17. 一句话速记版本
- HashMap = key-value + hash 定位 + 冲突处理 + 扩容
