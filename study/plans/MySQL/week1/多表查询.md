##  先准备两张示例表


```sql
-- 部门表
CREATE TABLE dept (
  id   INT PRIMARY KEY AUTO_INCREMENT, -- 主键自增
  dname VARCHAR(50),
  loc  VARCHAR(50)
);
INSERT INTO dept VALUES
 (10, '研发部', '北京'),
 (20, '人事部', '上海'),
 (30, '财务部', '广州'),
 (40, '销售部', '深圳');   -- 销售部暂时没有员工

-- 员工表
CREATE TABLE emp (
  id       INT PRIMARY KEY AUTO_INCREMENT,
  name     VARCHAR(50),
  job      VARCHAR(50),
  mgr      INT,           -- 直属领导的 id
  sal      DOUBLE,        -- 工资
  comm     DOUBLE,        -- 奖金
  dept_id  INT            -- 所属部门，关联 dept.id
);
INSERT INTO emp VALUES
 (1,  '曹操', '总裁',   NULL, 15000, NULL, 10),
 (2,  '司马懿', '经理', 1,    12000, 500,  10),
 (3,  '张辽', '开发',   2,     8000, 200,  10),
 (4,  '许褚', '开发',   2,     7500, 100,  10),
 (5,  '刘备', '经理',   1,    11000, 300,  20),
 (6,  '关羽', '人事',   5,     6000, 100,  20),
 (7,  '张飞', '人事',   5,     5500, NULL, 20),
 (8,  '诸葛亮', '经理', 1,   13000, 800,  30),
 (9,  '周瑜', '会计',   8,     7000, 200,  30);
```

记住几个关键事实：



* **40 号销售部没有员工**。

* **曹操的 mgr 是 NULL**（他是最大老板，没有领导）。

* 这些 "边界数据" 是后面外连接、自连接、子查询的灵魂。



***
```sql
-- 为什么需要多表查询？
SELECT *
FROM emp, dept
where dept_id = dept.id; -- 消除笛卡尔积 （多表查询必须写连接条件，否则就是笛卡尔积垃圾数据）


--   //内连接
-- 隐式内连接（用 WHERE） AND + 其他过滤条件
select e.name,d.dname
from emp e,dept d
where e.dept_id = d.id
and d.dname is not null;

-- 显式内连接（用 INNER JOIN ... ON） WHERE + 其他过滤条件
select e.name
from emp e
inner join dept d on e.dept_id = d.id
where d.dname is not null;



--  //外连接（OUTER JOIN）
--  内连接会丢掉 "对不上" 的行。但有时候我们想保留某张表的全部行，这就要用外连接

-- 左外连接
select d.dname,e.name
from dept d
left join emp e on d.id = e.dept_id;

-- 右外链接
select d.dname,e.name
from emp e
right join dept d on e.dept_id = d.id;



-- //自连接 (关键点：必须起别名)
select e.name '员工',m.name '领导'
from emp e
left join emp m on e.mgr = m.id; -- 两张emp表都必须起别名



-- //子查询 （重点）
SELECT * FROM emp
WHERE sal > (SELECT sal FROM emp WHERE name = '张辽');
--           └────── 子查询：先算出张辽的工资是 8000 ──────┘
-- 外层就变成：WHERE sal > 8000SELECT * FROM emp

-- 标量子查询
SELECT * FROM emp
WHERE dept_id = (SELECT id FROM dept WHERE dname = '研发部'); -- 外层用 = > < 等比较

-- 列子查询
SELECT * FROM emp
WHERE dept_id IN (SELECT id FROM dept WHERE dname IN ('研发部','财务部')); -- 外层用 IN ANY ALL 等接受列条件

-- 表子查询
-- 第一步：先按部门算出平均工资（这是一张虚拟表 t）
--   dept_id  avg_sal
--   10       10625
--   20       5833
--   30       10000

SELECT e.name, e.sal, t.avg_sal
FROM emp e
JOIN (
    SELECT dept_id, AVG(sal) AS avg_sal
    FROM emp
    GROUP BY dept_id) t -- 创建虚拟表别名
    ON e.dept_id = t.dept_id    -- 把虚拟表 t 跟 emp 连起来
WHERE e.sal > t.avg_sal;


-- //联合查询（union）
-- 概念：把两条结构相同的select结果上下拼起来
-- 两条select的列数，类型必须一致

-- union：合并后去重 [慢]
select name,sal,comm from emp where sal > 8000
union
select name,sal,comm from emp where comm > 300;

-- union all: 不去重 [快]
select name,sal,comm from emp where sal > 8000
union all
select name,sal,comm from emp where comm > 300;

/*  题目：查询 "每个部门的部门名、部门人数、部门平均工资"，要求没有员工的部门也要显示（人数显示 0，平均工资显示 NULL）。
    思路拆解：
    要显示所有部门 → 用 dept LEFT JOIN emp。
    按部门分组 → GROUP BY dept.id。
    统计人数：COUNT(e.id)（不能 COUNT (*)，否则销售部那行也算 1）。
    平均工资：AVG(e.sal)。
*/

select d.dname,count(e.id) 人数,avg(e.sal) 工资
from dept d
left join emp e on d.id = e.dept_id -- 左外连接
group by d.id,d.dname; -- group by 用于对齐普通列和聚合函数列的颗粒度
```

##  一页速查表



| 知识点   | 关键字                            | 记忆点                  |
| ----- | ------------------------------ | -------------------- |
| 笛卡尔积  | 多表忘写连接条件                       | 多表必写连接条件             |
| 隐式内连接 | `FROM A,B WHERE A.x=B.y`       | 老式写法                 |
| 显式内连接 | `FROM A JOIN B ON ...`         | **推荐**，连接 / 过滤条件分开   |
| 左外连接  | `A LEFT JOIN B ON ...`         | **A 全保留**，B 没有就 NULL |
| 右外连接  | `A RIGHT JOIN B ON ...`        | B 全保留                |
| 自连接   | `FROM emp e JOIN emp m ON ...` | 必须起别名                |
| 标量子查询 | `WHERE x = (SELECT 一行一列)`      | 接 `= > <`            |
| 列子查询  | `WHERE x IN (SELECT 多行一列)`     | 接 `IN / ANY / ALL`   |
| 表子查询  | `FROM (SELECT ...) t`          | 放 FROM 后，**必须起别名**   |
| 联合查询  | `... UNION ALL ...`            | 列数类型一致；不去重用 ALL      |

### 一句话总结



* **要 "两边都对得上" → 内连接**。

* **要 "某张表全保留" → 外连接（左 / 右）**。

* **一张表当两张用 → 自连接（起别名）**。

* **先算个子结果再过滤 → 子查询**（看返回是 "一个值 / 一列 / 一张表" 来决定怎么接）。

* **结果上下拼 → UNION ALL**。
