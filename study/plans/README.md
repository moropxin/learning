## 二、每天怎么用这份计划

1. 早上打开本周文件，**只看今天那一行**，别一次读完。
2. 按当天"看课章节 → 动手任务 → 验收标准"的顺序做，时长达标就停，不要"再多看一点"。
3. 每天结束 `git commit` + 在 [`PROGRESS.md`](PROGRESS.md) 写 3 行日志。
4. 周日：对照"自查 3 问"口述一遍，勾掉本周打卡。

## 三、改计划的规则

- **只在周日晚改**，周中不改计划（避免每天重新规划、实际不动手）。
- 落后 ≤2 天：周日机动时间补，当周不欠账。
- 落后 >3 天：按周文件末尾"减法清单"砍内容，**总周期不延长**。
- 换课程/换项目：先改 `README.md` 的课程表和时间线，再改对应周文件，最后改 `PROGRESS.md`（三处必须一致）。
