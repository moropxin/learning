## 学习笔记（示例，建议你改成自己的话）
- 我学到：
  - array_reverse 的核心是从两端互换元素，停止条件是左指针 >= 右指针。
  - remove_element 用写指针覆盖要删除的元素，保留元素的相对顺序不变，返回写指针的值作为新长度。
  - 两数之和的哈希方法是先查找需要的补数是否已经出现过（如果出现过则找到一组解），否则把当前数加入记录表中。
- 我不太理解：
  - 哈希表内部是如何处理冲突（示例中用线性探测，可能需要更多练习才能理解）。
