# Day 5 — 二叉树遍历（Tree Traversals）

## 今日目标
- 理解并实现二叉树的前序 / 中序 / 后序遍历（递归与迭代实现）。
- 实现层序遍历（BFS）。
- 构建若干测试用例，验证不同实现输出一致性，并记录遇到的问题与收获。

## 本日产出
- tree_traversals.c：包含树的构建、递归与迭代的前/中/后遍历、层序遍历以及简单测试。
- README.md（本文件）：说明如何编译、运行与验证结果。

## 文件列表
- tree_traversals.c — 主实现与测试程序
- README.md — 使用说明与测试案例（本文件）

## 如何编译与运行
在本地（Linux / macOS / Windows WSL）使用 gcc：

```bash
# 编译
gcc -std=c11 tree_traversals.c -o tree_traversals

# 运行
./tree_traversals
```

在 Windows（命令提示符或 PowerShell + mingw/msys2）：

```powershell
gcc -std=c11 tree_traversals.c -o tree_traversals.exe
./tree_traversals.exe
```

## 期望输出（示例树）
示例树（层序数组表��为 [1,2,3,4,5,-1,6]，-1 表示 NULL）运行后期望看到：

- pre rec/iter: 1 2 4 5 3 6
- in  rec/iter: 4 2 5 1 3 6
- post rec/iter: 4 5 2 6 3 1
- level: 1 2 3 4 5 6

如果递归与迭代版本输出不一致，请检查实现细节（尤其是迭代后序算法）。

## 测试用例建议
- 空树（应无输出且安全返回）
- 单节点树
- 完全二叉树（如示例）
- 只有左子树或只有右子树的链状树（测试最大深度情况）
- 含 NULL 节点的不完整树（使用层序数组构建时含 -1）

在 tree_traversals.c 的 main() 中已经包含示例构造与运行，你可以在该文件中调整测试数组以便做更多验证。

## 常见问题与注意点
- 迭代后序遍历实现容易出错（推荐用两栈法或单栈 + 记录上次访问节点的方法），运行多例子以验证正确性。
- level-order（层序）使用队列，注意队列实现要防止越界（示例代码是为练习简化，可在大输入时改为带动态扩容或计数的循环队列）。
- 对于非常深的树（退化为链），递归可能导致栈溢出，测试时注意树深度。

## 遇到的问题（示例记录）
- 在实现迭代中序时忘记将 cur 指向右子树，导致死循环。
- 在简易队列中未检查容量可能在大树上覆盖内存。
