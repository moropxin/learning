## 六、高频坑 / 减法清单

- Mapper 接口和 XML 的 `namespace` 对不上，报 `Invalid bound statement`——先查这个。
- 只写 XML 不写接口：先定接口再写 XML，减少改错。
- **减法顺序**：先跳 MyBatis 二级缓存 → 再跳多模块 → 再跳 PageHelper（手写 limit 也行）；`#{}`、动态 SQL、关联查询不能跳。

## 七、面试一句话

> MyBatis 中 `#{}` 和 `${}` 的区别？
> `#{}` 是预编译占位符，会替换成 `?` 并做类型处理，能防 SQL 注入；`${}` 是字符串拼接，直接拼进 SQL，只用在动态表名/列名这类不能预编译的地方，且必须自己做白名单校验。
