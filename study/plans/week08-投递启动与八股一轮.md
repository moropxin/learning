## 六、高频坑 / 减法清单

| 坑 | 说明 |
| --- | --- |
| 只看八股不口述 | 面试是"说"不是"看"，看不懂的地方一开口就露 |
| 简历写"精通" | 二本学生写"精通 Java"是负分，写"熟悉/能独立完成" |
| 只投大厂 | 本周全部投小厂/外包/创业公司，先拿面试 |
| 投递不带招呼语 | BOSS 上一句"您好，我在深圳，1/4 可到岗 6 周，做过 SpringBoot CRUD 项目"比简历附件有效 |
| 项目只讲"我学了什么" | 要讲"我做了什么、遇到什么问题、怎么解决" |
| 八股陷进 JVM 调优 | 小厂不问，先把基础四块打牢 |

**本周减法（已执行）**：JVM 内存模型/GC 调优 → 只记"堆栈方法区+分代"一句；并发 AQS → 跳过；分布式理论（CAP/BASE）→ 只记名词。
**不能砍**：MySQL 索引与事务（你的强项，要讲得比面试官细）、ArrayList/HashMap 底层、缓存三兄弟、项目 20 问。
