## 七、面试一句话

> JWT 和 Session 有什么区别？项目为什么用 JWT？
> Session 存在服务端，靠 Cookie 里的 SessionId 找回，天然支持「踢人下线」，但服务端要存、集群要共享；JWT 把用户信息签在 token 里，服务端无状态、适合前后端分离和多端，但无法主动失效。项目用 JWT + Redis 存 token 白名单，兼顾无状态和可控失效。
