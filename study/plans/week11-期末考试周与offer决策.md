# W11 · 期末考试周 + offer 决策 + 入职准备

> 2027-01-04（一）– 01-10（日）｜档位：E 最低速｜里程碑：**M6 寒假实习 offer 敲定（01/10 前）**

> 这周你大概率在考场上，学习降到 **60–90 分钟/天**。只有三件事不能停：**考试、面试电话、offer 沟通**。
> 你 1/10 放假、1/11（一）可到岗 → 对公司的话术是「**1/11 可全时到岗，连续实习 5 周至 2/14**」，这是你最强的谈判点。

## 一、本周目标

1. 期末不挂科（每天保底 45 分钟）。
2. 面试照接；面试前一晚只过项目 20 问，不学新内容。
3. **01/10 前敲定 offer**：到岗日期（1/11）、时长（5 周）、每周天数（4–5 天）、补贴、是否签实习协议、有无转正/暑期机会。
4. 若 01/10 仍无 offer → **立刻启动 B 方案**（见 §六），不要空等。
5. 入职前环境与代码复习一遍。

## 六、高频坑 / 减法清单

| 坑 | 说明 |
| --- | --- |
| 为实习旷考 | 挂科影响毕业与暑期实习，**考试优先** |
| offer 只口头说 | 到岗时间、时长、补贴必须有聊天记录/邮件 |
| 空等 offer 不准备 B 方案 | 01/10 没 offer 就启动 B：寒假全职苍穹（2 周）+ 点评（2 周）+ 3 月春招 |
| 以为实习就完事 | 实习期晚上 1.5–2h 必须推进项目，否则春招简历只有"一段实习"没有"项目" |
| 面试全停 | 期末考试周也接电话，小厂面试常约在工作日中午/晚上 |

**本周减法（已执行）**：所有新知识 → 停；算法 → 停；项目新功能 → 停。
**不能砍**：考试、面试、offer 确认、入职准备。

**B 方案（01/10 无 offer 时立即执行）**：1/11–1/24 全天 5h 做苍穹外卖（跟完主流程）→ 1/25–2/07 全天 5h 做黑马点评（缓存 + 秒杀 + 分布式锁）→ 2/08–2/14 打磨简历 v2 + 项目 README → 2/15 开学起春招密集投递（用"两个项目 + 深圳可到岗"投 50 家）。

## 七、面试一句话

> **你什么时候能到岗？能实习多久？**
> "我 **1 月 10 日放假，1 月 11 日（周一）就能全时到岗，可以连续实习 5 周到 2 月 14 日，每周 4–5 天**，人在深圳，通勤没问题。如果双方合适，暑假我可以再来做 2 个月，也希望能有转正或留用的机会。"——**把"只有 5 周"说成"1/11 可立刻全时到岗"**，在校生最有力的谈判点就是这个。
