## 七、面试一句话

> **秒杀怎么防止超卖？**
> 三层。第一层在 Redis 里用 Lua 脚本把"判断库存 + 判断是否已下单 + 扣库存"合成一次原子操作，避免并发下的检查与扣减脱节；第二层用 Redis Set 做一人一单，`SADD` 返回 0 就说明重复；第三层落地到数据库时用 `stock > 0` 作为 `UPDATE` 的条件，靠数据库行锁兜底。异步下单是为了把"扣库存"和"创建订单"解耦，接口先返回排队中，后台线程池再落库。
