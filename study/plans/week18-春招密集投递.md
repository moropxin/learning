# W18 · 春招密集投递（50 家）+ 八股一轮收口

> 2027-02-22（一）– 02-28（日）｜档位：E 冲刺｜里程碑：**春招投递 50 家完成**

> 春招的核心不是"学得更多"，而是"**投得更多、面得更多**"。这周每天固定投 8 家，用投递量换面试量。
> 二本学生的现实：投 50 家 → 8–12 个面试 → 2–4 个 offer，这是正常转化率，**不要因为前 10 家没回应就怀疑自己**。

## 一、本周目标

1. 投递 50 家（深圳 30 + 广州/东莞/佛山 20），A/B/C 三档按顺序投。
2. 每天跟进已投公司（BOSS 主动打招呼），维护投递表状态。
3. 八股一轮收口：五块各 10 条能连续口述。
4. 算法：力扣累计 60 题（简单为主，中等挑高频）。
5. 收到面试就暂停当天学习，全力准备。

## 六、高频坑 / 减法清单

| 坑 | 说明 |
| --- | --- |
| 只投不跟进 | BOSS 上要主动发消息，等待等于放弃 |
| 招呼语千篇一律 | 三种版本：技术匹配型 / 到岗时间型 / 项目亮点型，按 JD 选 |
| 投了没回应就停 | 50 家是最低量，没回应改简历再投 |
| 面试来了还学新东西 | 面试优先，学习顺延 |
| 算法完全放掉 | 每天 1 题保手感，笔试很常见 |

**本周减法（已执行）**：不做新项目；不学新技术；不刷难题。
**不能砍**：投递量、跟进、八股口述、被问倒清单。

## 七、面试一句话

> **你为什么选择投我们公司？**
> "我看了 JD，主要用的是 SpringBoot + MySQL + Redis，和我实习期间以及自己项目里用的技术栈是一致的，我能直接上手；另外我人在深圳，可以立刻到岗，也接受先做基础模块做起。我看重的是能真正参与业务开发，而不是只做边角料。" ——**不要空泛地夸公司**，讲"匹配 + 能到岗 + 想干什么"。
