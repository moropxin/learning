# W19 · 春招面试周 + 补漏

> 2027-03-01（一）– 03-07（日）｜档位：E 冲刺｜里程碑：**至少 3 场真实面试**

> 前两周的投递开始转化成面试了。这周的主线只有一条：**面试 → 复盘 → 补漏 → 再面**。
> 每场面完当天必须写复盘，否则同样的题会第二次答砸。

## 一、本周目标

1. 完成 3 场以上面试（真实或模拟）。
2. 每场当天写复盘：答砸的 3 题 + 答好的 2 点 + 下次改的 1 件事。
3. 补漏主打两类：**项目追问**（表设计/并发/缓存一致性）和**手写代码**（单例/快排/二分/链表反转）。
4. 投递维持每天 5 家（面试间隙补量）。
5. 算法保持每天 1 题。

## 二、时间节奏（E 冲刺档：面试/复盘 70 + 补漏 50 + 投递 20 + 算法 20 + 记录 20 = 180 分钟）

| 时间块 | 分钟 | 做什么 |
| --- | --- | --- |
| 面试/复盘 | 70 | 面试 + 当天写复盘 |
| 补漏 | 50 | 只补"被问倒的题"，不按教材顺序复习 |
| 投递 | 20 | 每天 5 家 + 跟进 |
| 算法 | 20 | 力扣 1 题 |
| 记录 | 20 | 被问倒清单 + 日志 |

## 六、高频坑 / 减法清单

| 坑 | 说明 |
| --- | --- |
| 面完不复盘 | 复盘比再面一家更值钱 |
| 面试失败就自我否定 | 春招正常转化率 5–10% 面试→offer，被拒是常态 |
| 按教材顺序复习 | 只补"被问倒的"，效率高 3 倍 |
| 手写代码不练 | 小厂/外包常让白纸写，丢分很亏 |
| 面试不问结果 | 面完主动问"大概什么时候有结果" |

**本周减法（已执行）**：新知识 → 停；新项目 → 停；难题 → 停。
**不能砍**：面试、复盘、补漏、投递维持。
