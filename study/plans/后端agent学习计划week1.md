# 后端agent学习计划 — Week 1：Java 语法巩固 + 算法线启动（非零基础）

## 本周目标
- 已学过 Java 基本语法，本周不从头学：用「自查 + 刷题」查漏补缺。
- 启动算法线：力扣简单题 + 蓝桥杯真题入门（Java 提交）。
- 补齐工程习惯：IDEA 调试、Git 提交规范。

## 每日任务（每日约 4 小时：含每天 30-40 分钟算法）
- Day 1：语法自查——变量/运算符/流程控制：做 30 道基础题（自测/面经），只补错点，不重复听课。
- Day 2：数组与字符串专项：力扣 1（两数之和）/ 26（去重）/ 344（反转）等简单题。
- Day 3：方法重载、参数传递巩固 + 力扣 2 题（如 27、283）。
- Day 4：综合练习：学生成绩管理系统（数组 + 方法，快速重写一遍）。
- Day 5：力扣 HOT100 入门（数组/字符串 3-4 题）+ 注册蓝桥杯官网，熟悉题库与提交方式。
- Day 6：蓝桥杯真题 2 道（简单/中档，Java 提交）+ 建立刷题笔记模板（思路/复杂度/易错点）。
- Day 7（周日）：Agent 支线——LLM/Agent 概念入门，周复盘。
