# 后端agent学习计划 — Week 1

## 本周目标
- 快速复习数据结构基础的第一模块：数组、字符串与排序的核心概念与实现（使用 C 语言）。
- 能实现并测试数组反转、字符串反转与快速/归并排序的基本版本。
- 在本地安装好开发工具（编译器、Git）并在 GitHub 创建仓库结构。

## 每日任务（每日约 2 小时）
- Day 1（数组与字符串、复杂度）：概念+实现数组反转、删除元素、两数之和（暴力+哈希）。
- Day 2（排序）：实现快速排序、归并排序、插入排序；比较时间复杂度与稳定性。
- Day 3（链表）：实现单链表基本操作、链表反转、合并两个有序链表。
- Day 4（栈与队列、递归）：实现数组栈、循环队列、括号匹配、练习递归分治。
- Day 5（二叉树基础）：实现前/中/后/层序遍历（递归与迭代）。
- Day 6（哈希/堆/图入门）：实现频率统计、简单小顶堆的插入/删除、理解 BFS/DFS。
- Day 7（环境搭建与 Java 体验）：在 Windows 上安装 JDK 17、IntelliJ IDEA、Git；创建第一个 Java 项目并写 HelloWorld 和字符串反转。

## 本周产出要求（Push 到 GitHub）
- 仓库路径：study/plans/ds-practice/week1/
- 每天一个文件夹：day1/day2/...，包含代码、README 与简单测试（或运行说明）。
