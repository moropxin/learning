# 后端agent学习计划 — Week 1：Java 语法基础

## 本周目标
- 搭建 JDK 17 + IntelliJ IDEA + Git 环境，熟悉 IDEA 日常操作。
- 掌握 Java 基本语法（变量、数据类型、运算符、流程控制、数组、方法）。有 C 基础，用「对比 C 语言」的方式加速。

## 每日任务（每日约 4 小时：约 2h 看课 + 2h 敲代码）
- Day 1：JDK/IDEA/Git 安装配置，第一个 Java 项目 HelloWorld，IDEA 快捷键。
- Day 2：变量、数据类型、运算符、Scanner 输入。
- Day 3：流程控制（if/switch/for/while），循环综合练习。
- Day 4：数组（一维/二维/遍历/冒泡排序）与数组工具类。
- Day 5：方法（重载、参数传递）与 String 常用 API。
- Day 6：综合练习：学生成绩管理系统（数组 + 方法，CLI）。
- Day 7（周日）：Agent 支线——LLM/Agent 概念入门（黑马 AI 课程/文章），周复盘。
