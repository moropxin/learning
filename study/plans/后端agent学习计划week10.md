# 后端agent学习计划 — Week 10

## 本周目标
- 测试、容器化与持续集成基础：JUnit 测试、Docker 打包、简单 GitHub Actions CI。
- 部署一个小服务到云（或使用免费平台）。

## 每日任务（每日约 2 小时）
- Day 1：JUnit5 进阶测试（Mocking、集成测试简介）。
- Day 2：Dockerfile 基础，打包 Spring Boot 应用为镜像。
- Day 3：使用 Docker Compose 本地运行数据库 + 应用。
- Day 4：GitHub Actions 简介：写一个简单的 CI 流程（构建与测试）。
- Day 5：把应用部署到免费平台（Heroku / Railway / Render）的准备工作。
- Day 6：实践部署或模拟部署（演练发布流程）。
- Day 7：整理并写部署文档。
