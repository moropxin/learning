# 后端agent学习计划 — Week 4

## 本周目标
- 哈希表、堆、图的进阶与实际应用，完成一些中等难度题目。
- 准备 Java 环境切换：开始理解面向对象思想，准备学习 Java。

## 每日任务（每日约 2 小时）
- Day 1：哈希表进阶（处理冲突、负载因子、哈希函数思想）。
- Day 2：堆与优先队列（实现 top-k、合并 k 个有序链表）。
- Day 3：图算法入门（BFS/DFS、最短路径概念）。
- Day 4：实践题（模拟 LRU、实现简单哈希映射）。
- Day 5：代码阅读（阅读一个 200 行左右的 C 项目模块并注释）。
- Day 6：Java 前置知识：类、对象、封装的概念（理论阅读）。
- Day 7：复盘并整理 week1–4 的练习到 GitHub。
